# 🍳 ResepKu - Aplikasi Resep Makanan

Selamat datang di **ResepKu**! Aplikasi mobile yang memudahkan Anda untuk menemukan, membuat, dan berbagi resep makanan favorit Anda.

## 📱 Tentang Aplikasi

ResepKu adalah aplikasi mobile berbasis **Flutter** yang dirancang untuk memberikan pengalaman terbaik dalam mengelola resep makanan. Dengan antarmuka yang intuitif dan fitur-fitur lengkap, Anda dapat dengan mudah menjelajahi ribuan resep, membuat koleksi resep pribadi, dan berbagi kreasi kuliner Anda dengan pengguna lain.

---

## ✨ Fitur Utama

### 🔐 Autentikasi & Akun
- **Register** - Daftar akun baru untuk memulai
- **Login** - Masuk ke akun Anda
- **Logout** - Keluar dari akun

### 🏠 Browsing & Eksplorasi
- **Home** - Halaman utama dengan rekomendasi resep terbaru
- **Detail Resep** - Lihat informasi lengkap resep termasuk bahan dan cara memasak
- **Pencarian** - Cari resep berdasarkan nama atau kategori
- **Favorit** - Simpan resep favorit untuk akses cepat

### 📝 Manajemen Resep Pribadi
- **Resep Saya** - Lihat daftar semua resep yang telah Anda buat
- **Tambah Resep** - Buat dan unggah resep baru
- **Edit Resep** - Perbarui resep yang sudah ada
- **Hapus Resep** - Menghapus resep dari koleksi Anda

### 💬 Interaksi Sosial
- **Komentar Resep** - Berikan komentar dan feedback pada resep
- **Share Resep** - Bagikan resep dalam bentuk teks ke platform lain

### 👤 Profil & Pengaturan
- **Profil** - Lihat dan kelola profil pengguna Anda
- **Edit Foto Profil** - Perbarui foto profil Anda
- **Ganti Password** - Ubah password akun Anda untuk keamanan

## 🚀 Cara Memulai

### 1. Clone Repository
```bash
git clone https://github.com/HildaKholifah/ResepKu_PPL.git
cd ResepKu_PPL
```

### 2. Install Dependencies
```bash
flutter pub get
```

### 3. Setup Backend
Pastikan backend API sudah berjalan. Lihat [Backend ResepKu](https://github.com/HildaKholifah/Backend_ResepKu) untuk instruksi setup.

### 4. Jalankan Aplikasi
```bash
flutter run
```
