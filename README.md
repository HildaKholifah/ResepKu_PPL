# app_resepku

📱 ResepKu - Flutter App

## Deskripsi

ResepKu adalah aplikasi mobile berbasis Flutter yang digunakan untuk mengelola dan menampilkan resep makanan. Aplikasi ini terhubung dengan backend API (Laravel + XAMPP + MySQL) yang berjalan di local server.

---

## Teknologi yang Digunakan

- Flutter
- Dart
- HTTP (API Integration)
- Laravel Backend (PHP)
- MySQL Database
- XAMPP (Apache & MySQL)
